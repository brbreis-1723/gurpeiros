# Gerador de Magias

Esse é o **Gerador de Magias de Dominio** com as funcionalidades:

* Criação e edição das magias conforme regras de Magias de Dominio
* Importação e Exportação de magias em arquivo JSON
* Visualização do grimório (Impressão/PDF)

!!! info "Armazenamento em Arquivo JSON"
    O Arquivo JSON serve para armazenar as magias criadas pelo gerador funcionando como um "grimorio virtual". Sempre que precisar editar basta importar o arquivo no gerador, fazer os ajustes e exportar novamente para outro arquivo JSON. 
  
    Além disso, o arquivo JSON gerado pelo jogador pode ser enviado ao mestre para ser acrescentado a lista oficial de magias disponíveis na seção **[Grimório de Magias](../magia/grimorio.md)**.

Para mais informações sobre como utilizar o **Gerador**, consulte o **[Manual do Sistema](../../material/gerador-magias/gerador-magias-manual.md)**
